# Roadmap

1. **Foundation:** contracts 2.0, snapshot validation and parsing, import graph, Next.js App Router routes, GitHub acquisition, analysis worker.
2. **Feature engine:** call resolution, effects, feature detection, branches, stages, unknown parts, captions; fixture app; `codedna analyze --json`.
3. **Learning engine:** concept catalog and detection, lessons, learning path, challenge generators.
4. **Learning UI:** 4a design tokens, Start, My App, Feature Story player, local progress; 4b concept cards, challenges, skill map, end-to-end tests.
5. **Local CLI:** `npx codedna` analyzes the current folder and serves the UI on localhost.
6. **Test it:** branch scenarios, coverage view, test skeletons, `npx codedna test`.
7. Optional AI helper · 8. Explore library · 9. VS Code.
