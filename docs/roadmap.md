# Roadmap

1. **Foundation:** workspace, contracts, minimal web entry point, and CI.
2. **Analysis foundation (this phase):** snapshot validation and file-level TypeScript/JavaScript dependency analysis with an in-memory resolver. The core remains independent of acquisition and UI.
3. **Product experiences:** build architecture and UI flow maps, impact analysis, and learning mode on validated analysis results; add repository acquisition adapters.
4. **Extension and maturity:** integrate the same core into the VS Code extension, expand language coverage, and harden performance and compatibility.

Later phases are directional, not a commitment to a specific parser or service.
